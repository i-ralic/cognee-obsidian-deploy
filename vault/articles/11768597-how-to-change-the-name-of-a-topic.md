The name of the topic can be changed both in the extension and the Dashboard.

## Changing the topic name when using the extension

-   Open the Extension and find the Topic you want to rename.

-   Click the **pencil icon** next to the Topic name, or simply **double-click** on the name once the Topic is open.

-   Type the new name and click on the **checkmark** to save the changes.

## Change the Topic name from the Dashboard

-   On your **Dashboard**, find the Topic you want to rename.

-   **Click on the Topic name** to start editing.

-   **Type the new name**.

-   **Press Enter** to save it.
