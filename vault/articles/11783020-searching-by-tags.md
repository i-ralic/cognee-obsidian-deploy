You have two ways to search using tags:

## Quick Tag Search (from a snippet)

-   **Click on a tag** inside any snippet - this will open the search bar and show all snippets that use that tag.

## Searching by Tags

-   **Use the search bar** on the dashboard (top right corner).

-   Type the tag name together with the **#** symbol (e.g. `#ideas`) to see all related snippets.
