When sharing topics and clusters created in Cluing with external collaboratores, you have the option to set **Access Roles**.
​

This gives you more control over who, how and when can interact with the insights you choose to keep.

Currently, supported roles are:

1.  **Viewer** - Can view snippets and comments for shared topics/clusters

2.  **Commenter** - Can leave comments and reactions on snippets

3.  **Editor** - Can add and remove snippets from a shared topic/cluster

While Clusters and Topics in the Team Version are by default shared with all members of the team, access to some information can be limited by adding **[[articles/11769020-private-clusters-team-version|a private cluster.]]**
