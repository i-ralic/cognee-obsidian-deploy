Everything an Autonomous Agent actually does happens inside a **Task**.

The Agent sets the ground rules and the Task is where you write the specific brief for the specific job.

### Create a new Task:

1.  Open the Agent page

2.  Click the **\+ button** next to the Agent that should run this Task.

3.  Give the Task a **Name**

4.  Write the **Description** - the more detail, the better the result

5.  Click Create Task

Created Task won't imidiately start running.

The Task opens in its own view, with the sidebar still on the right - this is your chance to check the brief once more, add any files the Agent will need, and get everything in order before you start it

> [!warning]
> 📌 You can edit a Task's Description later. Just don't rewrite it mid-run. Start a fresh Task if the direction has really shifted.
