You can annotate webpages on mobile in **three ways**:

1.  **On [[articles/13390501-edge-mobile-extension|Edge Mobile]]** (with the Cluing extension)

2.  **On [[articles/11822721-how-to-get-the-cluing-mobile-extension|Firefox Mobile]]** (with the Cluing extension)

3.  **On any mobile browser** (without extension, using the Cluing Mobile Apps)

## Annotate webpages on Edge Mobile (extension required)

Once you have the [[articles/11839924-mobile-extension-on-microsoft-edge|extension on Edge installed]], capturing snippets inside your mobile browser is super simple:

-   Open any webpage.

-   Highlight a piece of text you want to save.

-   A shortcut button (small pop-up) will appear next to your selection.

-   Click **"Save Highlight"** button to open a quick-save window.

From there, you can:

-   **Choose a Topic and a Cluster** where you want to save the snippet

-   Add a comment, **tag,** or **[[articles/11793611-how-to-mention-collaborators-in-comments|mention]]** someone

-   Confirm and save, all in a few clicks

> [!warning]
> 💡 **Also works on Firefox Mobile**
> You can annotate webpages on Firefox Mobile the same way.
> Just install the Cluing extension and follow the same steps.

## Highlight and Annotate with the Cluing Mobile App

If you don't want to install an extension, you can use the Cluing mobile app with the built-in [[articles/12267724-cluing-reader|Cluing Reader]].

Here's how:

1.  Download the Cluing mobile app - available for [iOS](https://apps.apple.com/us/app/cluing/id6759099072) and [Android](https://play.google.com/store/apps/details?id=io.cluing.apps&hl=en_US)

2.  Open the app and tap the **Reader icon** in the bottom navigation bar

3.  **Paste the link** to the webpage you want to annotate

The page will open inside Cluing Reader, where you can highlight text, add comments, [[articles/11793611-how-to-mention-collaborators-in-comments|mention]] teammates, and add #tags.
