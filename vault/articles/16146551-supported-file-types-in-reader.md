You can upload files from your computer and read, highlight, and collaborate on them the same way you would on any saved article.

## Supported file types

-   **PDF** (`.pdf`)

-   **Word** (`.docx`)

-   **Excel** (`.xlsx`, `.xls`)

-   **CSV** (`.csv`)

-   **Rich text** (`.rtf`)

Everything above opens as a clean, readable document you can highlight, comment on, and save snippets from.

> [!tip]
> 💡 Working with content in an unsupported format? Save it as a PDF or Word file first, then upload that.
