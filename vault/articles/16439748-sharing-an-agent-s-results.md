When you create an Agent in a team workspace, three things become visible to everyone on the team:

-   **The Agent itself** - its name and its ground-rule instructions.

-   **The list of Tasks it has run** - so anyone can scan what this Agent has been doing.

-   **The Connectors it uses** - since Connectors are workspace-wide, every Agent inherits them automatically.

> [!note]
> 📌 Anyone in the workspace can also **run their own Task** under your Agent. The Agent is a shared role, not a personal assistant.

## **Teammates permissions**

Here's what teammates can actually do with your Task:

-   **Read the full conversation** - every message you sent to the Agent, and every message it sent back.

-   **See the results** - anything the Agent produced, right in the Task view.

-   **Download any attached files** - reports, exports, drafts. Once downloaded, they're normal files your teammates can forward anywhere.

-   **Open the shareable link** - if the Agent created one, it sits in the Task's attachments section alongside the files. Teammates can click it to open the preview, or copy it and share it further.

> [!note]
> **📌 _Your Task is yours to run._** _Teammates can read along, but only you can send messages inside it. If they want to take the Agent in a new direction, they start their own Task._

## Sharing outside your workspace

There are two ways to send an Agent's result to someone outside the workspace:

-   a quick preview link

-   a publish to stay live([[articles/16440049-publish-to-your-own-domain|private domain]] - optional)

## Quick preview link

You'll find it at the top of the Task's **Attachments** section - ready to copy open.

It shows a clean preview of whatever the Agent built (a website, a financial report, an app preview, a pitch deck, a dashboard) live in the browser - no screenshots, no exports, no zip files.

> [!note]
> ⏰ **The preview link is live for 15 minutes.** Long enough to show a client on a call or drop into a message someone will open now.

## Publish to the web

When the result needs to stick around, hit the **Publish** button in the Task and check _Publish to the web_. Cluing hosts it on a permanent URL - nothing to set up, no expiry to worry about. Simply copy the link and send it.

And if you'd rather it lived somewhere that looks like you - `reports.yourcompany.com` instead of a Cluing URL - you can point [[articles/16440049-publish-to-your-own-domain|Publish at your own domain]].

## Downloadable files

Any file the Agent attaches to a Task lives in the same attachments section as the shareable link. You can download it, teammates can download it, and once it's a file on someone's disk it's a normal file — send it wherever you'd send any other attachment.
