For each collaborator, you can set different access levels - giving you full control over your work.

-   **Owner -** Has full access

-   **Editor -** Can edit and comment on the content

-   **Commenter -** Can only view and comment on the content

-   **Viewer -** Can only view the content

> [!danger]
> 📌 **Note:** Team workspace members have a default **EDITOR role** on each Cluster/Topic inside of it unless the owner of the Cluster sets it to be Restricted.
