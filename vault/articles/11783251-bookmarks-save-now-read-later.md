Bookmarks help you quickly save important pages for future research. Use them to easily revisit articles, websites, or any content when you don’t have time to dive in right away.

## **#1 Create a Bookmark Using the Extension**

-   Open the page you want to save.

-   Open the Cluing extension.

-   Click the **Bookmark button**.

<video src="/media/2519156015/bookmark---the-extension.mp4" aria-hidden="true" width="1910" height="986" autoplay loop muted playsinline preload="metadata" ></video>

## **#2 Create Bookmark Using a Shortcut**

-   Open the page.

-   Don’t select any text.

-   Press **Alt + Shift + S** to save it as a bookmark.

<video src="/media/2519168451/bookmark---shortcut.mp4" aria-hidden="true" width="1910" height="986" autoplay loop muted playsinline preload="metadata" ></video>

## #3 Paste a Link to Save it as a Bookmark

To create a bookmark using a link:

-   Go to your **Dashboard**.

-   Select the **Topic** where you want to save the bookmark.

-   Click the **Quick Add button**.

-   Choose **Add Link**.

-   Paste it, and your link is saved as a snippet
