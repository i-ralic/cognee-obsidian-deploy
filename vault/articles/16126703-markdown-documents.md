Reader lets you upload PDFs and [[articles/16146551-supported-file-types-in-reader|other supported files]] and read them as clean, structured Markdown right inside the Cluing Reader - simple readable content you can highlight and reference.

## **How it works**

1.  Upload a file to your workspace

2.  Cluing processes the file and opens it in Reader

3.  Files are automatically turned into a clean, structured Markdown document - with headings, lists, and paragraphs preserved

## **Uploading a PDF**

PDFs are a little different — when you upload one, you get to choose how it's saved:

-   **Text Document** - converts the PDF into clean, structured Markdown you can read and highlight in Reader.

-   **Regular PDF** - keeps the original PDF layout, exactly as it looks in the file

![](/media/2573339058/TextPDF.webp)

## **Supported document formats**

-   PDF (`.pdf`)

-   Word documents (`.docx`)

-   Excel spreadsheets (`.xlsx`, `.xls`)

-   CSV files (`.csv`)

-   Rich Text Format (`.rtf`)
