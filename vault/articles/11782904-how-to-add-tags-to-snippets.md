Tags are like **keywords** that you can use to **categorize your snippets**.

There are 2 ways of adding #tags as part of your snippets:

## Add Tags Directly to a Snippet

1.  Find a snippet you want to add #tag to

2.  Click on the 3 dots in the top right corner of the snippet

3.  Type the tag you want to add

4.  Press Enter

<video src="/media/2514371140/add-tags-to-snippets.mp4" aria-hidden="true" width="1910" height="986" autoplay loop muted playsinline preload="metadata" ></video>

You can add tags both in the **extension** and from the **dashboard**, making it easy to organize and find your content.

## **Editing and Deleting Tags**

1.  Go to Create #tag

2.  Type the name of the tag you want to edit

3.  Click the **wheel button** on that tag

4.  Make your changes or confirm deletion

<video src="/media/2514376945/edit-tag.mp4" aria-hidden="true" width="1910" height="986" autoplay loop muted playsinline preload="metadata" ></video>

> [!warning]
> 📌 **Note:** When you edit or delete a **#tag**, the change applies across your entire workspace. Every snippet using that #tag will be updated or lose the tag.

## **Adding Tags Inside Comments**

If you type **#something** in a comment, the system automatically turns it into a tag - while keeping the **#word** visible in your comment.
