The maximum file size you can upload to Cluing depends on your plan. The same limit applies everywhere you upload a file - whether you're adding a Document in the **Reader** or attaching it in **AI Chat**.

## Maximum file size per upload:

-   **Hobbyist** (Free) — **2 MB**

-   **Professional** — **30 MB**

If your file is larger than your plan's limit, you can compress it, split it into smaller files, or upgrade to Professional for a higher limit.
