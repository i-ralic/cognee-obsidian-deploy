## Advanced Search

If you’re searching for multiple words, you can use operators to refine your results:

-   Use **`&`** to find snippets that contain _both_ words. Example: `word1 & word2`.

-   Use **`|`** to find snippets that contain _either_ word (or both). Example: `word3 | word4`.

-   Add **`-`** before a word to exclude results containing it. Example: `-word5`.

-   Use **`~`** for a fuzzy search when you’re unsure of the exact match.
