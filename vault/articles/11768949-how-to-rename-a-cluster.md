If you want to change the name of a Cluster, you can do it easily from your **Dashboard**.

Here’s how:

1.  Select the Cluster you want to rename

2.  Click the **settings** **button ⚙️** next to the Cluster name

3.  A panel will open on the right, where you can edit the Cluster name

![](/media/2469979763/image.webp)

That’s it - quick and simple! **_[Try it yourself in the interactive video here 👈🏼](https://app.arcade.software/share/4XQfHYaMh3QnaXnMUKOy)_**
