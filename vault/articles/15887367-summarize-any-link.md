## **How to Summarize Any Link (From Dashboard)**

1.  Go to your Dashboard.

2.  Select the Topic where you'd like to summarize a link.

3.  Click the **+** button in the top-right corner.

4.  Select **"Summarize Link"** and paste the link.

5.  After a few seconds, you'll get a **ready-to-use snippet** - all in a single step.

## **How to Summarize Any Link (On Your Mobile)**

1.  Open the **[[articles/13833323-cluing-mobile-apps|Cluing mobile app]]** and find the topic where you want to save the snippet.

2.  Tap the Topic where you'd like to summarize a link.

3.  Tap the **+** button in the top-right corner.

4.  Select **"Summarize Link"** and paste the link - this generates a short description of the article.

5.  After a few seconds, you'll get a **ready-to-use snippet** with that summary, all in a single step.
