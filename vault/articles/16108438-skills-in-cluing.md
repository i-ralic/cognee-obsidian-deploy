Skills in Cluing help you create reusable instructions that your AI agents can follow for specific tasks, workflows, or processes.
Give it instructions, and Cluing follows them whenever you call it - no need to re-explain the task each time.

A Skill combines two things:

-   **Instructions** - what you want your agent to do and how it should approach the task

-   **Knowledge** - the research, examples, documents, and insights that help the agent do the job correctly

Unlike standalone instructions, Cluing Skills stay connected to the knowledge behind them. This means your agents always work with the latest context you’ve collected.

## Before you start

Decide two things:

-   The workflow you want to reuse (what the agent should do, step by step)

-   The knowledge the agent needs to do it well (research, examples, guidelines, past work)

The knowledge will live in a Topic, so your Skill can pull from it every time it runs.

## How to create a Skill

1.  Open the **Skills** page

2.  Click to create a new Skill

3.  Fill in the required fields:

    -   **Skill title** - a short, recognizable name

    -   **Description** - when this Skill should be used

    -   **Instructions** - exactly what and how you want it to do

4.  Save it

Once saved, your Skill is ready for use.

> [!warning]
> **Pro Tip:** You can mention a Topic inside the instructions to ground the Skill in your own research.

## Using Skills

Once your Skill is saved, it's ready to use inside Cluing AI Chat.

1.  Open AI Chat

2.  Type in whatever you're researching or working on

3.  Tell the AI which Skill to use - for example: _"Use my Competitive Analysis skill for this"_

Cluing will pick up the instructions from your Skill and apply them to your request - no need to repeat yourself or re-explain the task.
